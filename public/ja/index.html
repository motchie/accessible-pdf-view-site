Accessible PDF View

PDF を見出しから読める文書に

見出しジャンプ、リスト移動、行と列の見出しがある表。ふつうの Web ページでできることが、PDF でもできます。

  • Chrome ウェブストアで入手
  • ソースコード（MIT）

何をするか

3 つの表示
表示 内容
リーダー 文書を組み直した HTML。構造タグがあれば作成者の指定を、なければ配置から推測した構造を使います。
オリジナル 元の PDF ページの見た目。テキストが取り出せない文書でも表示できます。
マークダウン コピーできるテキスト。リーダーと同じ内容か、解析器の生出力かを選べます。

通常は、PDF を開いた状態でツールバーのボタンを押すと開きます。設定で「PDF を開くビューアー」をこのリーダーに切り替えると、.pdf で終わるアドレスの PDF を直接開くようになります。切り替えたときだけブラウザが権限を確認し、元に戻すと返却します。

設計の原則

目で見て確認できないことを、断定しません。画像に説明がなければ「説明がありません」と言い、機械が読み取った文字には読むたびに出所を明示します。ページからテキストが取れないときは、画像なのか、文字が図形として描かれているのか、本当に空なのかを実際に調べてから言い分けます。

代替テキストの出所は、常に画面に表示されます
出所 表示
作成者が書いたもの そのまま表示します
文書作成ソフトの自動生成 自動生成された説明であることを明示します
この拡張機能が生成したもの AI による自動生成の説明であることを明示します
説明がないもの 説明がないと明示します

機能

リーダーでできること
機能 内容
見出しナビゲーション H キーと 1〜6 キーで見出しを移動します。ふつうの Web ページと同じです。
リストと表のナビゲーション 本物の HTML のリストと、行・列の見出しを持つ表。
リンクのナビゲーション すべてのリンクがそのままリンクとして残り、ブラウザのリンク一覧から移動できます。
画像の説明（Chrome のみ） 代替テキストがない画像を、端末内の AI が説明します。常に AI による自動生成であることを明示します。
スキャンページの OCR（Chrome のみ） テキストを取り出せないページを、端末内で文字認識します。読むたびに機械による読み取りであることを明示します。
文字とレイアウトの調整 文字サイズ、行間、段落の幅、書体を調整できます。読みやすさに配慮した書体も同梱しています。
テーマ ライト、ダーク、またはシステム設定に追従。
表示言語 英語または日本語。文書自体の言語とは独立して選べます。
構造の 2 つの読み方 作成者が付けたタグがあればそれを、なければ推測した構造を使用します。切り替えて見比べられます。

プライバシー

PDF はブラウザの中だけで解析されます。通常の利用で文書が外部のサーバーへ送信されることはありません。画像の説明や OCR に使う AI は、端末内で動くブラウザ内蔵のモデルです。

インストール時に要求する権限は 5 つで、そのいずれもホスト権限ではありません。インストールしただけでは、どのサイトへのアクセス権も得ません。任意のホスト権限が 1 つだけあり、「PDF を開くビューアー」をこのリーダーに切り替えたときにのみ要求し、元に戻すと返却します。

最新情報（これまでの変更点）

入手する

Chrome ウェブストアの Accessible PDF View

Chrome の「セーフ ブラウジング保護強化機能」を有効にしていると、インストールの際に「この拡張機能は、セーフブラウジング保護強化機能で信頼されていません」と表示されます。この表示は、Chrome ウェブストアのデベロッパーが、ポリシーを守って公開を続けた実績で判断されるもので、Google によれば、新しいデベロッパーは通常、信頼できると判断されるまでに数か月かかります。Accessible PDF View は 2026 年 9 月に公開したばかりのため、それまではこの表示が出ます。

インストールするには「インストールに進む」を選んでください。判断の材料として、要求する権限とデータの扱いをプライバシーに、ソースコード（GitHub）を公開しています。仕組みについては、Chrome ウェブストア ヘルプの「拡張機能をインストールして管理する」を参照してください。

Firefox 版はまだ公開していません。アドオンサイトへの掲載はこれからで、それまではソースコードから読み込んで試せます（Chrome 版と同じく Manifest V3 です）。なお画像の説明と OCR は Chrome の内蔵 AI を使うため、Chrome でのみ利用できます。
